## Limitations and deferred work

**NOT VISUALLY VERIFIED IN MINECRAFT.** This cloud environment has no graphical display or Xvfb. Parent input tests, geometry, image-source inspection, compilation and headless GameTests do not establish visual acceptance.

Campaign HP/temporary HP remain governed by the existing encounter system; direct dashboard mutation is intentionally unavailable. Campaign Inspiration requires a DM for awards. Race score increases, spellcasting, class combat effects, physical Minecraft equipment mapping, automatic leveling/XP awards, full Features/Spells redesign and DM dashboard redesign remain deferred. Recorded progression drives class-choice guidance; this is not a multiclass or automatic leveling engine. Legacy/custom grants need DM review and are retained rather than silently erased. Generic narrative notes remain in biography/notes, within the existing field limits.

Very small logical viewports use scrolling, smaller icons and a compact narrative-field selector. Normal fitting is supported by geometry evidence, not rendered acceptance. No requirement that depends on rendered appearance is marked PASS here.
